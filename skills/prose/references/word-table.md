# Words that carry no fact

Test each against the reader: does deleting the word change what they know?
If not, delete it rather than swapping in a synonym. Where the right column
says "state", the fix is a fact the writer has to go and find.

| Written | Write instead |
| --- | --- |
| leverage, utilise | use |
| in order to | to |
| prior to, subsequent to | before, after |
| due to the fact that | because |
| in the event that | if |
| it is worth noting that, it is important to note | delete; state the fact |
| simply, just, easily, seamlessly, effortlessly | delete |
| robust, powerful, comprehensive, performant | delete, or state the measured property |
| blazingly fast, state-of-the-art, battle-tested | delete, or give the number |
| enables you to, allows you to | you can |
| is designed to, aims to | say what it does |
| gracefully handles | say what it does: "retries three times, then returns `Timeout`" |
| out of the box | by default |
| streamline | name the change: fewer steps, less time |
| dive into, delve into | read, examine |
| functionality | function, feature |
| as needed, as appropriate | state the condition |
| and/or | "X, Y, or both" |
| e.g., i.e., etc. | for example, that is, or name the items |
| perform / conduct / undertake + noun | the verb: "compress", not "perform compression" |
| set up, spin up, go down | configure or install, start, stop or decrease |

"Etc." ends a list the writer did not finish. If the rest is obvious,
finishing it costs a line; if it is not, "etc." dropped content.
